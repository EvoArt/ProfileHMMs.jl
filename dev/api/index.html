API

ProfileHMMs.ForwardResult — Type
ForwardResult

nhmmer-style score of an alignment: envsc, the composition-adjusted Forward log-odds score of the envelope (nats); bias, the composition correction it contains (nats; the unadjusted score minus envsc); and bit_score, the final score in bits on nhmmer's scale.

source
ProfileHMMs.HMMProfile — Type
HMMProfile

Parsed representation of a single HMMER3 profile HMM.

Fields:

  • name: model name (e.g. "16S_rRNA")
  • acc: accession (e.g. "RF00177")
  • desc: description
  • length: model length (number of match states)
  • alphabet: alphabet string ("RNA" or "DNA")
  • nseq: number of sequences used to build the model
  • stats_msv, stats_viterbi, stats_forward: (mu, lambda) for E-value calculation
  • compo: background composition (log-odds, 4 values for ACGU/ACGT)
  • match_emissions: Matrix{Float64} (K × M) — match emission scores per node
  • insert_emissions: Matrix{Float64} (K × M) — insert emission scores per node
  • transitions: Matrix{Float64} (7 × M+1) — transition scores per node Row order: m→m, m→i, m→d, i→m, i→i, d→m, d→d Column 1 = node 0 (COMPO), columns 2:end = nodes 1:M
source
ProfileHMMs.Plan7HMM — Type
Plan7HMM

A nucleotide profile configured for local search. Build one with build_plan7. Scores are natural-log odds against a uniform background.

source
ProfileHMMs.SearchHit — Type
SearchHit

A profile hit. target_start:target_end are 1-based inclusive coordinates on the input sequence (on strand '+' or '-'); model_start:model_end are the aligned profile states. bias is the composition-bias correction subtracted from bit_score (bits; 0 with scoring=:viterbi, which does not compute it).

source
ProfileHMMs.ViterbiResult — Type
ViterbiResult

Best local alignment of a profile to a sequence: raw log-odds score (nats), bit_score (with HMMER's length-dependent null model), the 1-based inclusive aligned span target_start:target_end of the sequence and model_start:model_end of the profile (all 0 if there is no alignment).

ProfileHMMs.default_seed_bits — Method
default_seed_bits(hmm)

Ungapped seed threshold in bits. Chance seeds arise at a rate proportional to the model length M, and each costs a Viterbi window of about M × 1.5M cells, so the threshold grows as 3 log2(M): about 19 bits for 5S rRNA, 30 for 16S and 32 for 23S. Real hits have ungapped stretches far above these.

ProfileHMMs.forward_score — Function
forward_score(hmm, xs, a=1, b=length(xs); bias=true) -> ForwardResult

Rescore the alignment of hmm to xs[a:b] as nhmmer does: Forward score of the envelope a-20:b+20, composition-bias correction (unless bias=false), and normalisation to a window of the profile's MAXL.

ProfileHMMs.scan_fasta — Method
scan_fasta(hmms, fasta; evalue_threshold=1e-5, seed_bits=default_seed_bits,
           db_size=nothing, min_length=1, threaded=true, progress, io=stderr)

Search both strands of every sequence in fasta with one profile or a vector of profiles. Returns SearchHits sorted by sequence, position and strand.

  • evalue_threshold: report hits with E-value at most this. E-values are P-values times search_space of the whole file (as nhmmer), unless db_size fixes the multiplier.
  • scoring: :viterbi (default) reports the best alignment's Viterbi score. :forward also rescores each alignment as nhmmer does — Forward score, null2 composition-bias correction (bias), normalisation to a MAXL window and Forward-calibrated P-values — so that scores and E-values are comparable with nhmmer's. It costs a Forward and a Backward pass per hit.
  • seed_bits: SSV seed threshold in bits, a number or a function of the profile. Lower values trade speed for sensitivity to weak, gapped hits.
  • threaded: use all Julia threads.

ProfileHMMs.viterbi_score — Method
viterbi_score(hmm, xs) -> ViterbiResult

Score the best single local alignment of hmm to base indices xs. The flanking N/C states and the null model are configured for length(xs) as in HMMER, so scores do not drift with the length of the searched window.
